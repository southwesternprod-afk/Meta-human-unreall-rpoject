# AAA materials (project install)

This repo ships the `aaa-materials` toolkit at `plugins/aaa-materials` (also
installable as a Claude Code plugin from the `metahuman-tools` marketplace in
`.claude-plugin/marketplace.json`).

Read `plugins/aaa-materials/skills/aaa-materials/SKILL.md` now and follow it,
with `ROOT` = `plugins/aaa-materials` (relative to the repository root). The PBR
numbers are in `plugins/aaa-materials/skills/aaa-materials/reference/pbr-standards.md`.
